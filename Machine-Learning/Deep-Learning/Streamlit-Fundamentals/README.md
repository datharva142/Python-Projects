# 🌐 Streamlit Fundamentals

A beginner-friendly collection of Streamlit examples demonstrating how to build interactive web applications using Python.

These programs gradually introduce Streamlit concepts from simple text display to PDF processing and text chunking.

---

## 📚 Topics Covered

| File                           | Concept                     |
| ------------------------------ | --------------------------- |
| 79_streamlit_JayGanesh.py      | Basic Streamlit Application |
| 80_streamlit_Input.py          | User Input Widgets          |
| 81_streamlit_Button.py         | Button Events               |
| 82_streamlit_fileUpload.py     | File Upload                 |
| 83_streamlit_TextExtraction.py | PDF Text Extraction         |
| 84_streamlit_Chunking.py       | Text Chunking               |
