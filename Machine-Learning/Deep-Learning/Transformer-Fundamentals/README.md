# 🤖 Transformer Fundamentals

A structured collection of Python programs demonstrating the complete working of Transformer architecture from Self-Attention to GPT-style Decoder-Only models.

This repository focuses on understanding the mathematical and architectural foundations of modern Large Language Models (LLMs) such as GPT, BERT, Gemini, Claude, and Llama.

---
