# 🤖 AI Agent Fundamentals

A collection of beginner-friendly AI Agent examples demonstrating how autonomous systems make decisions, use tools, and maintain memory.

These examples gradually evolve from a simple rule-based chatbot into a memory-enabled AI agent.

---

## 📚 Topics Covered

| File                     | Concept                    |
| ------------------------ | -------------------------- |
| 87_AIAgent_RuleBased.py  | Rule-Based Agent           |
| 88_AIAGentCalculator.py  | Agent with Calculator Tool |
| 89_AIAGenyMultpleTool.py | Agent with Multiple Tools  |
| 90_AIAgent_Memory.py     | Agent with Memory          |

---

After completing these examples, you will understand the fundamental building blocks behind modern AI Agents used in systems such as ChatGPT Agents, AutoGPT, LangGraph Agents, CrewAI, and other autonomous AI workflows.

These programs provide the foundation required before learning:

* RAG Systems
* Agentic AI
* Tool Calling
* Memory Systems
* Multi-Agent Architectures
* Autonomous Workflows
