# 🧠 RNN Fundamentals

A structured collection of programs that explain the complete workflow of **Recurrent Neural Networks (RNNs)** for Natural Language Processing (NLP) and Sequence Modeling.

This module covers the journey from **text preprocessing and tokenization** to **embeddings, hidden states, activation functions, loss functions, training, prediction, and complete RNN architecture visualization**.

---

## 📌 Overview

Recurrent Neural Networks (RNNs) are neural networks designed to process sequential data by maintaining a memory of previous inputs through hidden states.

Unlike traditional neural networks, RNNs can learn relationships between words, sentences, and time-series sequences.

This learning module demonstrates the mathematical and practical implementation of RNN concepts using Python, NumPy, TensorFlow, and Keras.
